# Color

Reference swatches for design tools. The authoritative values live in SKILL.md Section 2.

| Name | HEX | Role |
|---|---|---|
| TC Slate | `#3A4B5C` | Primary — headings, structure |
| TC Text | `#111A22` | Body copy and captions only. Never with TC Yellow |
| Dark Navy | `#0F1C27` | Darker than slate when needed (text on yellow, deeper dark surface) |
| TC Yellow | `#FEB100` | Accent only — never text on white |
| TC Grey | `#DFDBDA` | Borders, card fills, neutrals |
| TC Blue | `#009BD6` | Accent |
| TC Green | `#6BA543` | Accent |
| White | `#FFFFFF` | Backgrounds, reversed logo |

## Accessible combinations

`accessible-brand-colors.webp` is the reference grid of text and background pairs with their WCAG contrast results. The working rules, including the extra palette colours it does not show, are in SKILL.md Section 2 (Smart Text Color on Backgrounds). Quick version: yellow text only on slate or Dark Navy; on yellow, text is slate or Dark Navy; never white or TC Text on yellow; never yellow on white or on TC Text. Backgrounds are always a brand colour, never black.

## Files

- `accessible-brand-colors.webp` — accessible text and background combinations (reference grid)

- `trusscore-brand-colours.cclibs` — Adobe Creative Cloud library. In an Adobe app, add it via Libraries to get the swatches in Illustrator, Photoshop, and InDesign.

- `trusscore.ase` — Adobe swatch exchange (Illustrator, InDesign)
- `trusscore.aco` — Photoshop swatches

Follow the 60-30-10 rule (Section 2).
